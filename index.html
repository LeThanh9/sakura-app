Hướng Dẫn Cài Đặt File .APK Trên Điện Thoại Android

  1. Bấm nút Tải Về trực tiếp trên trình duyệt Chrome/Cốc Cốc của điện thoại.
  2. Sau khi tải xong, nhấn mở file .apk từ thanh thông báo hoặc thư mục Download.
  3. Nếu điện thoại hiện cảnh báo "Cài đặt ứng dụng không rõ nguồn gốc", chọn Cài đặt ➔ Bật công tắc Cho phép từ nguồn này.
  4. Bấm Cài đặt và thưởng thức ứng dụng!

Hướng Dẫn Mở File .EXE Trên Máy Tính Windows

  1. Bấm Tải Về file cài đặt .exe.
  2. Nếu màn hình hiển thị "Windows protected your PC" (SmartScreen), hãy bấm vào dòng chữ More info.
  3. Chọn Run anyway (Vẫn chạy) để hoàn tất tiến trình cài đặt.
